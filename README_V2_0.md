# SECOND BRAIN OS V2.0 — FREE OFFLINE KNOWLEDGE ASSISTANT

Built on V1.4. Includes keyword search, extractive Q&A, extractive summaries, keyword/topic extraction, and clickable source notes. No paid API, API keys, new permissions, backend, or extra Firebase data required.

**Not a generative LLM:** Results are selected passages from existing notes. Does not invent answers or understand complex reasoning as a cloud model would.

## Install
1. Export JSON backup in current app.
2. Upload all ZIP contents to the same GitHub Pages repository, preserving `icons/` and Firebase settings.
3. Commit; allow Pages to deploy; close and reopen the PWA.
4. Select `AI Assistant` in the sidebar.

Data remains on device or syncs through the existing Firebase feature; the assistant itself sends no note text to an AI service.

## Testing
Create a note with a distinctive topic; search it in AI Assistant. Test each mode and click a source. Offline test after first successful load.
