Instal aplikasi ke layar utama Android melalui Chrome.

Memeriksa aplikasi…
  1. Buka halaman ini di Chrome Android, bukan browser dalam WhatsApp/ChatGPT.
  2. Jika tombol instal tidak aktif, tekan ⋮ → Tambahkan ke layar utama atau Instal aplikasi.
  3. Jika tertulis Sudah diinstal, cari Second Brain pada daftar aplikasi Android. Tidak perlu menginstal ulang.
  4. Jika hanya tersedia Buat pintasan, Chrome mungkin belum menganggap situs memenuhi syarat instalasi, atau aplikasi sudah terpasang.
